# Original demo loops

Sixty synthesized instrumental loops, generated by `scripts/generate-demo-tracks.py`.
No third-party recording or sample is used. These demos can be used, remixed,
and recorded with this application. They are short practice loops inspired by
House, Hip-hop, Afrobeat, Amapiano, Reggae, and Blues, rather than commercial songs.

PCM WAV, mono, 22,050 Hz, 16 bit. Each loop contains eight four-beat bars. Each of the six styles has ten variants.
To regenerate from the frontend directory: `python3 scripts/generate-demo-tracks.py`.
